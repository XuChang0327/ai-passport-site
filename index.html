▰使用指南▰

从开机即玩，到亲手创造新的玩法。

从 300+ 本体案例开箱即玩开始，到星瀚连接电脑化身游戏手柄，再让 AI 帮你创造属于自己的新玩法。

01

第一次使用 XINGHAN

打开猿编程 APP 社区即可查看 300+ 案例作品，开箱即玩，无需安装。

→02

恢复出厂固件

扫描设备二维码后，把专属链接拷贝到电脑上，再用电脑上的 Chrome 或 Edge 浏览器和 Type-C 线恢复默认固件。

→03

安装社区玩法

在玩法社区发现用户分享的小游戏、工具与创意互动，选择喜欢的安装到设备；安装后会覆盖设备当前的全部内容。

→04

创造自己的玩法

跟着官方文档创造玩法，把自己的小游戏和交互真正装进 XINGHAN。

→05

用 AI Agent 创造专属玩法

从一句清晰的需求开始，让 AI 编程 Agent 完成开发与构建，再把玩法安装到真实的 XINGHAN。

→06

用 Codex 创造 XINGHAN 玩法

在 Codex 中打开玩法项目，把想法写成可验收任务，完成构建、安装与实机迭代。

→07

用 Claude Code 创造 XINGHAN 玩法

让 Claude Code 理解玩法项目与硬件约束，生成可安装版本，并根据真实设备反馈继续完善。

→08

用 TRAE 创造 XINGHAN 玩法

在 TRAE Work 中描述玩法、完成代码与构建，再把新体验装进随身的 XINGHAN。
